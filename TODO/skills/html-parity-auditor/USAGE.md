# Uso de la skill local

## Cuando usarla

Usar esta skill local despues de:

- migrar una pantalla nueva a React
- tocar layout compartido
- cambiar estructura de datos en una pantalla
- modificar el contrato con backend

## Como usarla manualmente

1. identificar la pantalla a auditar
2. abrir su HTML de `docs/`
3. abrir la pagina React correspondiente
4. seguir `SKILL.md`
5. si hay diferencias, corregir codigo o actualizar documentacion

## Resultado esperado

La pantalla debe quedar:

- visualmente alineada con la referencia
- funcionalmente equivalente en lo ya migrado
- documentada de forma correcta
- respaldada por un contrato backend suficiente
